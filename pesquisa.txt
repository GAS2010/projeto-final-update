O que fazer se der problema no banco

Quando o navegador mostrar “Falha ao ... no banco”, olhe o terminal onde o npm start está rodando. Agora ele imprime o motivo real. 
Os casos mais comuns:

Erro de conexão ou “DATABASE_URL” inválida: o arquivo precisa se chamar .env (com o ponto). O que você enviou se chama _env. 
Dentro dele deve ter DATABASE_URL=postgresql://usuario:senha@host/banco?sslmode=require. Pegue a string atualizada no painel do Neon, 
em Connection Details. Se você trocou a senha lá, atualize o .env e reinicie o servidor.
Primeira requisição lenta ou com erro: o Neon suspende o banco quando fica parado. Espere alguns segundos e tente de novo.
Erro HTTP 4xx/5xx com texto do Postgres (por exemplo relation "categoria" does not exist): a tabela não existe. No SQL Editor do Neon, 
rode algo como:
sql
CREATE TABLE categoria (
  id_categoria SERIAL PRIMARY KEY,
  descricao VARCHAR(100) NOT NULL
);

Ajuste o tipo e o tamanho se a sua tabela for diferente.
4. Não consegue excluir uma categoria: provavelmente existe um produto ligado a ela (chave estrangeira). Exclua ou mude os produtos dela antes, 
ou use ON DELETE SET NULL na chave estrangeira.
5. Depois de qualquer mudança no código ou no .env: pare o servidor (Ctrl+C) e rode npm start de novo.

Nunca compartilhe o .env nem a DATABASE_URL, porque ela contém a senha do banco. Se já enviou a string para alguém, 
é bom trocar a senha no painel do Neon.
